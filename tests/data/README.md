# Test data

## dda_test.d

A synthetic Bruker timsTOF DDA-PASEF folder (analysis.tdf + analysis.tdf_bin,
28 KB) generated by Sander Willems, copied from the test data of
[timsrust_pyo3](https://pypi.org/project/timsrust-pyo3/) 0.4.1 (Apache-2.0).
Used by `tests/test_vendor_conversion.py`.

## RNA LFQ integration data

`tests/test_naseweis_lfq_native.py` generates a small mzML experiment in its
temporary test directory. The data are original synthetic test data under this
repository's BSD-3-Clause license, with no copied experimental measurements.
There is one negative-mode RNA target (`ACGUAG`, charge −2), four theoretical
isotope peaks calculated by pyOpenMS from its empirical formula, 121 centroided
MS1 scans at one-second intervals, and an elution peak centered at 60 seconds
with Gaussian sigma 8 seconds and height 200,000. A fixed low background and
unrelated constant peaks are included. The expected integrated isotope-envelope
area is `200000 × sqrt(2π) × 8`; the test allows 5% for peak boundary selection
and discrete integration. The generated mzML is smaller than 300 KB and is not
committed as a binary fixture.

The full LFQ workflow test also uses the existing, unchanged
`example-data/mzML/NME1.mzML` and matching NME1 FASTA. That experimental run
contains 512 negative-mode MS1 scans and 2,116 MS2 scans. Its established search
reference results remain unchanged because LFQ is optional and off by default.
